# Data Dictionary (Словарь данных витрины `mart_daily`)

| Колонка | Бизнес-смысл | Единица | Пример / Примечание |
|---|---|---|---|
| `city_id` | Идентификатор населенного пункта | Идентификатор | `c1`, `c2` |
| `city_name` | Официальное наименование города | Текст | `Москва`, `Санкт-Петербург` |
| `date` | Календарный день измерений | Дата | `2026-04-13` |
| `temp_mean` | Средняя температура за 24 часа | Градусы Цельсия (°C) | `14.5` |
| `temp_mean_rolling_3d` | Тренд температуры за текущий и 2 предыдущих дня | Градусы Цельсия (°C) | `13.2` (может быть `NULL` в первые 2 дня) |
| `precip_sum` | Общий объем выпавших осадков (дождь/снег) | Миллиметры (мм) | `0.0` (сухо), `12.5` (ливень) |
| `wind_speed_max` | Пиковая скорость ветра за сутки | Метры в секунду (м/с) | `8.4` |
