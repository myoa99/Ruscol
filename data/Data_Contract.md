## Naming & Units Rules (Правила именования и единиц)

1. **Стиль:** Все колонки строго в `snake_case`, без пробелов, кириллицы и спецсимволов.
2. **Даты и время:** 
   - `date` — дата в формате `YYYY-MM-DD` (`ISO 8601`).
   - `timestamp_utc` — метка времени в UTC.
3. **Запрет абстрактных имён:** Запрещены названия `value`, `data`, `metric`.
4. **Агрегаты:** Метрики-агрегаты содержат префиксы/суффиксы: `temp_mean`, `wind_speed_max`, `precip_sum`, `*_rolling_3d`.
5. **Фиксация единиц:** Все единицы измерения зафиксированы в данном контракте.

## Схема слоя Mart (`mart_daily`)

| Column Name | Dtype | Nullable | Unit | Description |
|---|---|---|---|---|
| `city_id` | `str` | **No** | — | Уникальный идентификатор города (бизнес-ключ) |
| `city_name` | `str` | **No** | — | Название города |
| `date` | `str` / `date` | **No** | — | Дата наблюдения (`YYYY-MM-DD`) |
| `temp_mean` | `float` | No | °C | Среднесуточная температура воздуха |
| `temp_mean_rolling_3d` | `float` | Yes | °C | Скользящая средняя температура за 3 дня |
| `precip_sum` | `float` | No | мм | Суммарное количество осадков за сутки |
| `wind_speed_max` | `float` | No | м/с | Максимальная скорость порывов ветра |

| Column Name | Dtype | Nullable | Unit | Description |
